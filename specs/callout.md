# 图表标注 callout · 规范（条目化索引）

> 本页职责：给每条规则一个稳定 ID + 指向实现位置，供代码注释回引与修订检索。
> 适用范围：当前仅直角坐标系（`CartesianChart`，柱 / 折线及其延伸）。无坐标系图族待接入时另补 ID。
> 分层：标注是 **L1 构件**（`core/callout.js`，收「已解析好的像素锚点 + 文案 + 障碍矩形」，
> 负责选位、算路径、画 DOM），**锚点解析留 L2**（`charts/cartesian/callout-anchor.js`，标 `[L2-LOCAL]`）——
> 「哪个数据点 → 哪个像素」要懂 band 尺、双 Y、datazoom 窗口与图例隐藏，全是图表专属知识。
>
> **三主题同形**：只有尺寸 / 字号 / 引线长走值 token，`behavior.json` 一个键不加（CALLOUT-15）。

## 为什么标注可以自动选位，而数据标签不行

[data-label.md](data-label.md) LABEL-01 写着「空间不足时按 LABEL-06 隐藏，**不做挤压位移**」，
该页待办更记着饼环「当初预估的纵向避让算法**没有发生**，定案是重叠即隐藏、不做位移」。
**本页的自动选位不推翻那条**——两者的绑定方式根本不同：

- **数据标签靠位置认领**它属于哪个数据点（柱顶正上方的那个数字就是这根柱的），挪走位置就读不出是谁 → 只能隐藏；
- **标注靠引线认领**，箭头指着谁就是谁。位置本就是自由的，挪动不损失任何信息 → 可以也应该自动选位。

换句话说：LABEL-01 禁止的是「为避让而破坏位置所承载的语义」。标注的位置不承载语义，故不在禁令范围内。

## 形态与绑定

| ID | 规则 | 实现 | 状态 |
|---|---|---|---|
| CALLOUT-01 | 一条标注 = **强调环 + 多行纯文字 + 带箭头曲线引线**，三者**同生共死**：任一放不下即整条不画。所有丢弃必须在**画线之前**判完——否则会画出一条指向空处的线（判例同 [pie.md](pie.md) PIE-12 的「引线与标签强绑定」）。**中间档「只画环不画文字」明确否决**：没有文字的环是一个无意义的圈 | `core/callout.js` → `renderCallouts` | ✅ |
| CALLOUT-02 | **锚点两档**：① 真实数据点（系列名 + 类目名）② 任意数值坐标（类目 + 数值，可选 `axis`）。band 尺、双 Y（必须经 `yOf(series)` 取尺，写死主轴在双 Y 图上会画错）、datazoom 窗口、图例隐藏一律在 L2 解析，L1 只收像素。**类目不在当前窗口内 / 系列被图例隐藏 / 该值为 `null` → 这条整体不出** | `charts/cartesian/callout-anchor.js` → `resolveCalloutAnchors` | ✅ |
| CALLOUT-03 | **文案由调用方写死整句**，组件不计算内容，故**不接** `core/chart-text.js`（那是「组件自己写死的文案」的家，见 [chart-text.md](chart-text.md)）。Ainvest 英文化走 `demos/chart-presentation.js` 的 `translateDeep` 全量深度遍历，加词条即生效 | `demos/examples.js`；`demos/chart-presentation.js` | ✅ |
| CALLOUT-04 | **强调环自绘**空心圆（`fill:none`，锚点落在柱顶时能看见柱），直径**含描边** = `size-callout-ring`，口径同 `size-line-point`。**不复用折线数据点**，四条理由：① 「任意数值坐标」档那里根本没有既有图元可复用，复用会立刻分裂成两档两套几何；② `size-line-point` 的语义被 LINE-01 占着，且被 LABEL-01 的净距公式消费（`linePointH`），共用会把两件事绑死；③ iFinD 的数据点是菱形（`behavior.json` 的 `line-point-shape`），环若复用点几何就要跟着做形态分叉，而强调环三主题同形；④ `mark.js` 的点是批量 join + 生长闭包的一部分，拆不出「画单个点」 | `core/callout.js`；`tokens/*.json §28` | ✅ |

## 自动选位

| ID | 规则 | 实现 | 状态 |
|---|---|---|---|
| CALLOUT-05 | **候选集 = 8 方位 × 近 / 远两档 = 16 个**，枚举序固定（即同分时的稳定破平手）。方位 = 文本块相对锚点的方向；定位规则一条通吃 8 向：**块上离锚点最近的那个点，恰好落在 `anchor + u × d` 上**（正向是近边中点，斜向是近角）。`d` 近档 = 环外缘 + `size-callout-leader`，远档 = 环外缘 + `size-callout-leader × FAR_RATIO`（模块常量 2，取比例不取像素，跟着各主题自己的 token 走） | `core/callout.js` → `CALLOUT_DIRS` / `calloutBlockRect` | ✅ |
| CALLOUT-06 | **两条硬约束，不满足即淘汰**（`scoreCandidate` 返回 `null`）：① 块必须**整体**落在 `bounds`（默认 `frame.grid`）内；② 与已定标注的块与环净距 ≥ `spacing-data-label-min-gap`。**一概不 clamp**——clamp 会把块推向锚点让引线退化甚至反向；tooltip（TOOLTIP-01）与轴贴片能 clamp，是因为它们没有引线，前提不同。硬约束而非惩罚分，让结果可断言、单测好写 | `core/callout.js` → `scoreCandidate` | ✅ |
| CALLOUT-07 | **打分优先级**（越小越好）：**压住图元 > 引线穿越图元 > 用了远档 > 方位偏好**。<br>覆盖度用 **7×5 网格采样**求，采样点命中即停 ⇒ **并集语义**。**不能用「重叠面积求和 ÷ 块面积」**：折线的逐段包围盒彼此大量重叠，面积求和会**重复计数**，密集数据下十六个候选一起饱和到 1、失去区分度，选位便退化成由方位偏好决定——2026-09-16 在 50 类目折线上实测，文字块因此被摆到线上。同理**穿越只记有无、不记条数**（段数随数据量线性增长，按条数计等于把「线很长」当成「挡得很厉害」）。<br>穿越检测用「锚点 → 块最近点」的**直线段**做保守代理（曲线求交太贵，曲线只在这条直线两侧小幅摆动）。方位偏好斜上最优、正下最差——正下方是 X 标签带方向，且柱从底部长上来 | `core/callout.js` → `coverageFraction` / `scoreCandidate` | ✅ |
| CALLOUT-08 | **多条标注按声明序贪心**：首条恒得全局最优位，其后每条把已定条目的块与环并入障碍集。声明序 = 优先级，由调用方决定。首个恒放 ⇒ 结果稳定、与容器变化单调（变挤只会更少、不跳变）——同 LABEL-06② 的 `dropCollisions` 品味 | `core/callout.js` → `placeCallouts` | ✅ |
| CALLOUT-09 | **放不下就不放**：近档 8 方位全灭 → 远档 8 方位；远档也全灭 → **整条丢弃**，不缩字号、不截断。**对齐 LABEL-06③ 而非 [pie.md](pie.md) PIE-16**——PIE-16 成立的三个前提在这里一条都不成立：① 它有**专门预留**的标签带，callout 挤在已有图元之间、没有任何预留空间；② 它截的是「名称段」这个身份索引、截短仍认得出，而 callout 是整句话，截掉后半句 = **错的句子**（这正是 PIE-16 自己那条「截断的数字是错的数字」的推广）；③ 它整条丢会丢掉扇区身份，而丢掉一条标注，柱 / 线 / 数据标签全都还在 | `core/callout.js` → `placeCallout` | ✅ |
| CALLOUT-10 | **单向无环**：`文案 → 定宽折行 → 批量测量 → 块尺寸 → 候选枚举 → 打分 → 选位 → 引线 → DOM`，一趟，不迭代、不做收敛判断。**块尺寸不由可用空间反推**——折行宽是 token 常量 `size-callout-max-width`，与 `bounds` / 障碍物 / 其它标注全都无关。这是 `charts/pie/geometry.js` `alignOutside` 那条教训的直接套用：那里「带宽由文本宽反推 ↔ 文本按带宽截断」互为因果，靠「带宽由容器定死、单向一趟」才切断；标注会踩的是同一个环的变体「选位依赖块尺寸 ↔ 块尺寸依赖可用空间」。**折行必须锚常量而不是锚剩余空间**，改这里之前先把那段注释读完 | `core/callout.js` 文件头；`wrapByWidth` | ✅ |

## 引线与箭头

| ID | 规则 | 实现 | 状态 |
|---|---|---|---|
| CALLOUT-11 | **引线 = 三次贝塞尔**，但**两端切向刻意不对称**：起点侧沿长轴离开文字块（文字横排，水平 / 垂直离开才像从字里拉出一条线），**终点侧沿锚点方向到达**（`c2 = base − u × 0.5·跨度`）。<br>⚠️ **终点侧不能照抄 `charts/sankey/layout.js` 那条对称 sigmoid**：桑基两端都接在竖直的节点边上、方向恒为水平，而标注的到达方向 `u` 是任意的。2026-09-17 实测，两端都轴对齐会让**斜向方位的箭头变形**（见 CALLOUT-12）。**不用二次贝塞尔**——它只有一个控制点、曲线恒向一侧凸，画不出 S 形；弦图那条二次贝塞尔是「以圆心为唯一控制点」的向心弓形，是另一件事。<br>起点 = 块 AABB 上离锚点最近的点、再朝锚点让开 `spacing-4`（文字不贴线），终点在环外缘。**起点、底边、尖端、锚点四点共线**，这是最好验证的不变量。退化：`u` 正交时两端恰好同轴，曲线退化为直线，不抛错、不产生 `NaN` | `core/callout.js` → `calloutLeader` | ✅ |
| CALLOUT-12 | **箭头 = 手写三角 `<path>`，不用 SVG `<marker>`**（同 WATERFALL 的方向头与 [chord.md](chord.md) CHORD-05）。**曲线止于底边、三角形补到尖端**（照 `charts/waterfall/index.js` 的 `directionLine → baseY` + head 补齐），否则线头会从三角形里穿出来。<br>要求是**等腰正三角：尖端落在底边中点正前方**、高 = `HEAD_H`、底 = `HEAD_W`、尖端指向锚点。这要求曲线的**到达方向与三角形轴向一致**，即 CALLOUT-11 的不对称切向；两者一旦分家，三角形就被压扁——2026-09-17 实测，两端轴对齐时斜向四个方位夹角 45°、面积由 15.00 掉到 10.61（`=15×cos45°`）。<br>⚠️ **验收必须断言三角形自身的形状**（等腰、面积、尖端朝向），**不能断言「底边 ⊥ 末端切线」**——那是构造公式本身，照抄成测试则实现怎么错它怎么绿，上面那个变形就是这样漏过去的

| CALLOUT-14 | **层级与命中**：标注层在**数据标签之上、水印之下**追加（本仓库层级 = DOM 追加顺序，同 [watermark.md](watermark.md) WATERMARK-05 / LABEL-08）。整层 `pointer-events: none`，不抢 hover / tooltip 命中。**不参与图例 hover 的 `applyDim` 弱化**——标注是作者刻意的重点，不该因为 hover 别的系列而变淡；它跟随系列的那部分已经由「系列被隐藏就整条不出」（CALLOUT-02）表达了 | `charts/cartesian/index.js` → `build()`；`charts/styles.css` | ✅ |
| CALLOUT-15 | **入场生长期间整层隐藏、结束后出现**，标注不参与生长补间（与数据标签同一口径，见 [motion.md](motion.md) MOTION-05）。<br>**三主题同形，`behavior.json` 一个键不加**：三家的标注是同一个空心环、同一条 S 曲线、同一个三角箭头、同一套选位算法，差的只有直径 / 字号 / 引线长这些**数值** → 全走值 token。对照两个反例边界就清楚：`pie-label-form` 进 behavior.json 是因为它**改变标签块的宽高**并直接参与碰撞区间与画布半高计算，标注没有这类分叉；`legend-select` 曾错放进去、2026-08-12 被迁出，判据是「源文档从未指定哪个品牌用哪种」，标注同理（另见 data-label.md 头部「`behavior.json` 没有也不应有数据标签形态键」） | `tokens/{ths,ifind-pc,ainvest}.json §28` | ✅ |
| CALLOUT-16 | **标注不改变任何既有图层的位置。** 它是叠加层：只能叠上去，不能反过来重排下面的东西。数据标签、坐标轴刻度、图元一律不因为「这个点被标注了」而移动——开关标注只让标注自己出现或消失，基图**逐像素不变**。<br>⚠️ **2026-09-17 曾短暂违反过这条**（让被标注点的数据标签给强调环让位），当天撤销，三条理由按分量排：① **仓库里所有叠加层都是非侵入的**（水印、数据标签、轴标题、十字线没有一个会移动它下面那层），让位会使标注成为唯一的例外；② **开关会改变基图**——同一份数据只因为有人加了批注，标签位置就不同，在以「展示规范间距」为目的的组件库里这个耦合是反的；③ **它违反 [data-label.md](data-label.md) LABEL-10 的契约**：`labelHeadroom` 在算比例尺**之前**就定死为 `labelLineH + labelGap`，让位的那几像素**没进 headroom**，刻度正好落在数据最大值上（100% 利用率）时标签会冲出轴顶。实测当时没冲出去，靠的是 `niceSplit` 取整多给的 10.5px 余量，**不是设计保证**——正是「默认预览永远看不见」的那类隐患。<br>**代价，明说**：强调环必须钉在数据点上（CALLOUT-04），而数据标签按 LABEL-01 就停在图元外 `spacing-data-label-gap`（THS 4px），环外缘却有 `size-callout-ring / 2`（THS 6px）——**被标注且有数据标签的点，环会与标签小面积交叉**。这是本条不变量换来的，不是缺陷。文字块与引线不在此列：它们已把数据标签纳入避让集（CALLOUT-07），实测重叠面积 0。彻底消掉交叉要给环 / 箭头 / 文字加背景色光晕（`paint-order: stroke`），见待办 | `charts/cartesian/index.js`（**无代码**，靠不做任何事成立） | ✅ |

## 活 demo

标注的**内容住在示例对象上**（`example.callout`，不在 `cfg(n)` 里），主站右栏的 **标注** 旋钮**默认关、打开才注入**——
与 `axisTitle` 完全同构。**可选叠加层一律默认关**：画廊缩略图与详情页首屏都应是图表的规范原貌，批注由人主动打开。

> 基础柱状图 / 基础折线图——全站最「基础」的两张图——缩略图都带着批注。当天改回。
> 当时「默认开」的理由是「示例声明了内容就该显示」，但 `axisTitle` 也是示例声明内容、却默认关，
> 这条理由区分不了两者，不对称是拍脑袋定的。画廊卡片的覆盖对象里所有可选叠加项都显式写 `false`，加新叠加项时照做。
没声明标注内容的示例**不出这个旋钮**（按示例条件化，`capabilitiesOf` 里同 `ratingStyle` / `area` 的写法）。
当前两个宿主示例：**基础柱状图**（柱顶档一条）与 **基础折线图**（真实数据点档 + 任意数值坐标档各一条）。

> 分组轴保持「一个分类 = 一种图形」——标注是横切能力，和数据标签 / 轴标题 / 水印 / 动效一样走旋钮，
> **不自立分类**。曾短暂建过一个「标注」分组，2026-09-17 撤销：`柱顶标注` 本质就是柱状图，
> 却被挪出了柱状图组；等别的族接入时，那些示例该放进「标注」还是放回本族，两个答案都不对。

- **打开旋钮再关掉**：标注整条出现 / 消失，而**基图逐像素不变**（CALLOUT-16）——数据标签、刻度都不动。
- **三主题横向对比**：环直径、字号、引线长按 §28 的值 token 分化，形态完全一致。
  实测 THS 环 r=5.25 / 描边 1.5px，iFinD-PC 与 Ainvest r=6 / 2px；深色下环与引线翻成白 60%。
- **两种引线形态各看一个**：柱顶档选到斜上方位 → 三次贝塞尔 S 形；折线档常选到正东 →
  Δy=0，曲线**按设计退化为直线**（CALLOUT-11 的退化档，不是没画出来）。
- **拖「项数」滑杆**（主站详情页是 range 输入 `#density-slider`，不是分段按钮）：这是本能力最该看的一档——
  障碍物密度由它决定。**稀疏档几乎怎么写都对，密集档才真正考验选位**：标注会换方位、拉远档，
  挤不开时整条消失（CALLOUT-09），而**先声明的那条一步不动**（CALLOUT-08）。
- **开缩放轴**把锚点类目移出窗口 → 整条标注消失；移回来又出现（CALLOUT-02）。
- **点图例隐藏标注所在系列** → 整条消失；hover 别的系列 → 标注**不变淡**（CALLOUT-14）。
- 明暗切换验证文字色随模式翻转（CALLOUT-13 复用 LABEL-09 的判断）。

## Do / Don't

- ✅ **Do**：改环大小 / 字号 / 引线长 = 改 `tokens/*.json §28`（三主题同步，合同校验会拦）；改方位偏好 = 改 `callout.js` 里 `DIR_BIAS` 一个常量，不动算法；新图族接入 = 自己算锚点像素后调同一个 `renderCallouts`。
- ❌ **Don't**：给 `callout.js` 写 `if (theme === …)`（三主题同形，CALLOUT-15）；为标注往 `behavior.json` 加形态键；在 JS / CSS 里写标注色值字面量；**为放下标注而缩字号、截断文案或把块 clamp 回边界**（规则是换位，换不动就整条丢弃，CALLOUT-06 / 09）；**让折行宽依赖可用空间**（CALLOUT-10 的环）；把 `.dv-data-label` 拿来挂标注文字（CALLOUT-13）；用 SVG `<marker>` 画箭头（CALLOUT-12）。

## API

```js
CartesianChart(host, {
  callout: [
    { series: '营业收入', category: '3', text: '同比 +18%，创近八个季度新高' },  // 档① 真实数据点
    { category: '7', value: 620000, text: '监管新规发布' },                      // 档② 任意数值坐标
  ],
})
```

全是**数据与语义配置**：标在哪、写什么。样式（颜色 / 字号 / 环大小 / 引线长 / 方位）一律走 token 与算法，**API 一概不收**。
缺省 = 不传即无标注。预览面的「标注」旋钮不是组件 API——它在 L3 决定要不要把示例自带的 `callout` 装进 cfg，默认不装。
