端与明暗切换后三张卡片会整体重绘：端影响 --font-size-axis / 网格线粗细与轴的行为旋钮， 明暗切换整套文本与网格色。左侧切分类换图形，三主题横向对比同一份数据。 数据量对所有分类生效（类目数 4 / 16 / 36）：看柱容器收缩（BAR-03）、X 标签碰撞（AXIS-06）、 折线数据点显隐分档（>13 全隐）；多数据下折线含负值区。 轴标题开关给图表挂 axisTitle:{y,x}（双 Y 分类另有 y2）：默认不显示，开后 Y 标题在 Y 标签带上方另起一带、X 标题在 X 标签带下方另起一带；Y 标题贴自己那一侧的画布外缘 （左轴左对齐、右轴右对齐，标题多长都不会被裁），X 标题右对齐绘图区右缘 （specs/axis-title.md AXISTITLE-02/04）。文字样式与同卡片的 Y 轴标签同款——色 / 字号 / 行高 / 字重 四个 token 都别名到 *-axis，主题与端的分叉由轴标签自带（AXISTITLE-05）。 y2 仅真·双量纲（声明副轴）出，故折柱组合 三主题都出；iFinD-PC 非双量纲时的镜像反侧只是主轴同一套标签、不是第二根轴，那里不出标题（AXISTITLE-03）。 渐变面积开关给当前分类的主线（首条声明折线）挂 area:true—— 仅含折线且非堆叠的分类生效（specs/line.md）。 缩放轴开关给图表挂 zoom:{start,end}（初始窗口后 65% 类目）：主图只画窗口内类目、 拖手柄/拖选区/点击轨道即改窗口，Y 轴随可见数据重算（SCALE-02 / specs/datazoom.md）； THS/iFinD 轨道内双色迷你阴影、Ainvest 纯轨道（datazoom-data-shadow:false）。 动效开关控制入场生长（specs/motion.md）：柱从 0 轴竖向长高、折线自左向右拉线， 面积 / 堆叠填充带 / 数据点跟随同一条前沿；堆叠是整根一起长而非逐段接力（MOTION-06）。 时长处处统一 480ms（MOTION-02，motion-duration-grow）——切任意示例 / 数据量 / 主题都不变， 三主题横排时三张卡同时起跑、同时收束；缓动统一 cubicOut。 （源规范原本按生长占比分 320 / 480 两档，本仓库实测 33 种组合里只有 2 种落短档，故取消分档，见 specs/motion.md 偏差 1。） 只在实例首次挂载时播一次：拖缩放轴手柄、点图例显隐、拖拽卡片改尺寸都不得重放 （三处任一出现重放即缺陷，MOTION-04）；「重播生长」按钮重建三张卡片再看一遍，动任意旋钮同理。 生长期间数据标签整层不出、结束瞬间出现，坐标系 / 图例 / 轴标题 / 水印全程就位不参与生长（MOTION-05）。 关掉后应与不带动效时逐像素一致；系统开启「减弱动态效果」时开着也直接出终态（MOTION-07）。
