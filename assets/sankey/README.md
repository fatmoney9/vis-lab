# Sankey playback assets

The SVG files in this directory are exact exports from Figma node `0:28082` in
`RviSlVW7lNx9BacoSApBA0` (20230711 Sankey landscape).

- `play.svg`: circular playback button glyph.
- `period-arrow-prev.svg`: period navigation arrow; CSS mirrors it for previous.
- `slider-grip-line.svg`: one grip line, repeated three times on the range thumb.

The Ainvest period arrows are exact exports from the PC Figma node `110:2941` in
`Uv36h0PXzZG7ZhuHBHQ3qz` (AInvest treemap specification file). They are kept
separate because the Ainvest PC/mobile playback instance uses a different 16px
glyph from the THS/iFinD control:

- `ainvest-period-arrow-prev.svg`
- `ainvest-period-arrow-next.svg`

Keep these local copies instead of linking the temporary Figma MCP asset URLs.
