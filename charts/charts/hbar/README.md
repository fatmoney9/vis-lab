## 两处与众不同的用法

- **`grid` 画的是竖线不是横线**：本族的数值轴是**横轴**，所以读数参照系是竖向分割线。
  走的是 GRID-02 预留的 `showXSplit` 特例通道（那条规则的原文就是「X 轴分割线默认不显示，
  仅特例经 showXSplit 显式开启」），横向网格线一条不画——行与行之间靠间距区分，
  再加横线会把每一行框起来、读成表格。见 [specs/hbar.md](../../../specs/hbar.md) HBAR-21。
- **`motion` 同时用到两个驱动器，但只打断其中一个**：入场用 `runGrowth`（被打断落终态），
  逐期播放用 `runTween`。⚠️ **本族从不调 `runTween` 的 `pause()`**——暂停时让当前这一期
  自然播完再停（HBAR-16），因为停在两期之间的条不对应任何真实数值。
  驱动器本身的「取消即冻结」语义没变，见 [specs/motion.md](../../../specs/motion.md) MOTION-08。
